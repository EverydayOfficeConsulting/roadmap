Complete site kit

Recommended

One zip file with everything needed to rebuild the whole roadmap from nothing: your website files, the database setup, all your content and appearance settings, and a step-by-step guide written so someone who has never seen the setup can follow it, including accounts, your web address (domain) and sign-in emails.

  • START-HERE.html — the rebuild guide (opens in any browser)
  • website/ — every file from your GitHub repository (or at least index.html, admin.html and config.js)
  • supabase/ — two files to paste into the SQL Editor: the setup, then your content
  • backup/ — a restore file for this Backup tab, a modules spreadsheet and your user list
